# Life Dashboard v0.3.0

홈과 타임라인에 새로운 디자인을 적용했습니다.

- 홈: 청록색 테마, 브리핑, 2열 건강·일정 지표, 오늘 일정 및 생활 알림 카드.
- 타임라인: 시간 연결선과 유형별 아이콘, 달력 날짜 선택, 분류 필터와 원본 상세.
- 탐색: 하단 홈·타임라인, 상단 설정, 홈의 생활 알림에서 알림 보관함 진입.
- 오늘 일정은 저장된 유효한 일정만 표시하며, 종일 일정과 시작 시간순으로 정렬합니다.
- 수면은 데이터 귀속 기준에 맞춰 '오늘 종료된 수면'으로 표시합니다.

Android 15 이상이 필요합니다. 기존 서명을 유지하므로 0.2.0의 설정 → 앱 업데이트에서 업데이트할 수 있습니다. 저장 데이터와 DB 스키마는 유지합니다. 앱을 삭제할 필요가 없습니다.

검증: 단위 테스트 39개 통과. 배포 스크립트에서 Release 빌드·lint·인증서·버전·디버깅 비활성 여부를 확인합니다. 실기기 화면, 큰 글꼴 및 실제 업데이트 설치는 아직 검증하지 못했습니다.

문제 발생 시 앱 삭제 대신 후속 수정 버전으로 업데이트합니다. 기존 릴리즈는 보존하며, 배포 차단이 필요하면 문제가 있는 릴리즈의 최신 지정/공개 상태를 조정합니다.
