# Life Dashboard v0.8.2

- 일부 걸음 기록의 시간 범위를 Health Connect SDK가 변환하지 못해 건강 수집이 중단되는 문제를 보완했습니다.
- 해당 변환 오류에 한해 같은 페이지를 Android 원본 API로 다시 읽습니다. 정상 기록은 계속 처리하고 시간 범위 확인이 필요한 기록은 원본을 보존하며 확인 필요 상태로 표시합니다. 원본 앱의 기록을 삭제하거나 시각을 변경하지 않습니다.
- 변경 이력에서 같은 기록이 다시 전달되는 경우에도 동일한 복구 경로를 사용합니다. 권한·통신 등 다른 오류를 빈 결과로 무시하지 않습니다.
- 수집 완료 후 확인이 필요한 걸음 원본 수를 안내하고, 진단 보고서에 `SUCCESS_WITH_WARNINGS`와 해당 건수를 남깁니다. 걸음 합계는 기존 Health Connect 집계 API를 유지합니다.

업데이트 후 **설정 → 데이터 수집 및 권한 → 건강 연결 진단 → 진단 실행**을 눌러 주세요. 결과를 복사하면 수정 후 수집 상태를 확인할 수 있습니다.

Android 15 이상, 기존 서명과 DB 유지. 사용자 진단과 동일한 SDK 예외를 자동 테스트에서 재현하고 복구를 검증했습니다. 실제 단말의 같은 데이터로 수집이 끝까지 완료되는지는 업데이트 후 확인이 필요합니다.
