# Life Dashboard v0.4.0

- 홈의 일정·수면·걸음수·운동 카드를 누르면 설정한 앱을 엽니다. 설정 → 홈 카드 연결 앱에서 항목별로 선택하거나 해제할 수 있습니다.
- 연결 전에는 카드에서 바로 앱을 선택할 수 있습니다. 선택한 앱의 기본 화면만 열며 수집 소스는 바뀌지 않습니다.
- 제목 또는 본문이 `(광고)`로 시작하는 알림을 광고로 모읍니다.
- 알림 상세에서 결제·배송·예약·광고·기타로 분류를 변경하거나 자동 분류로 되돌릴 수 있습니다.
- 오늘의 브리핑을 홈에서 펼쳐 전체 내용을 볼 수 있습니다.
- 재집계 중 기존 집계값을 유지하고 상단에 집계 중 배지를 표시합니다.
- 수집 상태를 카드로 묶고 설정 아이콘을 톱니바퀴로 개선했습니다. 결제의 불필요한 보조 문구를 정리했습니다.

Android 15(API 35) 이상. 기존 앱과 같은 서명을 사용하며 저장 데이터와 DB 스키마를 유지합니다.
기존 알림은 수집 활성 상태의 새로고침 또는 설정 → 저장된 원본 다시 분석으로 재분류할 수 있습니다. 수동 분류는 재분석 후에도 유지합니다.

자동 테스트 및 Release 빌드·서명 검증을 거쳐 배포합니다. 실제 단말의 외부 앱 실행과 설치·UI 검증은 별도입니다.
