# Life Dashboard v0.5.0

- 앱 선택 화면에 아이콘, 앱 이름, 검색창과 현재 선택 표시를 추가했습니다.
- 동일한 일정은 제목·시작/종료·종일 여부 및 장소를 비교해 한 번만 표시하고 집계합니다. 일정 원본은 보존합니다.
- 설정 → 알림 파서 규칙에서 앱·문구·분류·결제금액 조건을 설정하고 예시로 테스트할 수 있습니다. 규칙 저장 시 기존 알림도 재분석하며 직접 분류는 유지합니다.
- ‘결제가 완료되었습니다’와 결제금액 라벨을 인식하도록 개선하고 배송 완료 오분류를 줄였습니다.
- 광고는 발생 시각부터 14일, 기타는 30일 후 원본까지 자동 삭제합니다. 기존 저장 알림에도 적용하며 수집 중지 중에도 앱 실행/약 6시간 주기 작업에서 정리합니다. 결제·배송·예약은 삭제 대상이 아닙니다. 삭제한 원본은 재분석으로 복구할 수 없습니다.
- 타임라인의 ‘건수 · 최신순’을 눌러 ‘시간순’으로 전환할 수 있습니다.
- 집계 입력이 같으면 재집계를 생략하고, 정상 수집 후 5분 이내 앱 복귀의 중복 수집을 줄였습니다. 직접 새로고침은 즉시 실행됩니다.
- 집계 배지는 0.7초 이상 걸릴 때 표시하며 기존 화면 값을 유지합니다. 홈의 수집 상태 카드는 제거하고 설정에서 확인하도록 정리했습니다.

Android 15(API 35) 이상. 기존 서명과 DB schema v1을 유지합니다.
기존 일정/알림 재분류는 수집 활성 상태 새로고침 또는 설정 → 저장된 원본 다시 분석으로 반영할 수 있습니다. Android 백그라운드 제한에 따라 주기 작업은 지연될 수 있습니다.

자동 테스트 및 Release 빌드·서명 검증 후 게시합니다. 실제 단말 설치와 UI/백그라운드 실행 검증은 별도입니다.
