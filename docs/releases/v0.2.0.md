# Life Dashboard v0.2.0

Android 15 이상을 지원하는 개인 생활 기록 앱의 첫 GitHub 릴리즈입니다.

- 설정에 앱 업데이트 페이지를 추가했습니다. 최신 정식 릴리즈, 변경 내용과 다운로드 진행률을 확인할 수 있습니다.
- 다운로드한 APK의 크기, SHA-256, 패키지, 버전, 기존 앱과의 서명을 검증한 뒤 Android 설치 화면으로 연결합니다.
- 알림 변환 오류를 격리하고 읽을 수 있는 원본을 보존합니다.
- 연속 알림의 집계 요청을 병합하고 날짜별 조회로 불필요한 전체 데이터 로딩을 줄였습니다.
- 생활 데이터는 기기에 저장하며 업데이트 확인/다운로드에만 인터넷을 사용합니다.

설치 파일은 LifeDashboard.apk입니다. 최초 설치 후 앱 설정에서 수집 동의와 필요한 권한을 허용해 주세요. 기존 0.1.0 앱에는 업데이트 페이지가 없으므로 이번 APK를 직접 설치해야 합니다.

자동 테스트와 APK 빌드를 검증했습니다. 개인 실기기의 반복 오류 해소 및 제조사별 설치/장기 백그라운드 동작은 별도 확인이 필요합니다.
