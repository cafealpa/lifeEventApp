# Life Dashboard v0.7.0

- 기존 홈 카드에 유형별 색상, 그라데이션, 강조 숫자와 세부 정보를 적용했습니다.
- 일정 카드에 진행 중·다음·종일 일정, 결제·예약 카드에 최근 기록, 배송 카드에 완료 알림 수와 최근 상태를 표시합니다.
- 별도의 오늘의 브리핑 화면과 생성·저장·아침 예약 기능을 제거했습니다. 이전 아침 예약은 앱 시작 시 취소합니다.
- 이전 브리핑 데이터는 삭제하지 않고 타임라인에서 제외합니다. 일정·알림·건강 수집과 일간 집계는 유지합니다.
- 기존 카드의 연결 앱 실행과 타임라인 이동은 그대로 사용할 수 있습니다.

Android 15 이상 지원. 기존 서명과 DB 구조를 유지합니다. 설정 → 앱 정보 → 앱 업데이트에서 확인할 수 있습니다.

실기기 화면·업데이트 설치·기존 예약 취소의 실제 동작은 아직 검증하지 않았습니다.
