# Life Dashboard v0.6.0

- 설정 첫 화면을 수집 요약과 5개 메뉴로 간소화했습니다. 각 상세 화면에서 권한, 홈 연결 앱, 알림 분류 및 보관, 데이터 관리, 앱 정보를 관리할 수 있습니다.
- 일정·알림·건강의 실제 권한 상태를 표시하며 건강 일부 허용과 선택 백그라운드 권한을 구분합니다.
- 오늘 브리핑을 오늘 활동·결제·배송 및 남은 일정 중심으로 개편했습니다. 숫자 카드와 상세 펼치기를 제공하고 시간 경과에 따라 일정 안내를 갱신합니다.
- 밝은 앱 화면에서 시스템 상태표시줄 아이콘 대비를 개선했습니다.
- 알림 파서 규칙의 화면 이름을 알림 분류 규칙으로 정리했습니다.

Android 15 이상에서 사용할 수 있습니다. 기존 앱과 같은 서명 및 DB 구조를 유지합니다. 설정 → 앱 정보 → 앱 업데이트에서 새 버전을 확인할 수 있습니다.

실기기 설치·권한 복귀·큰 글꼴 및 백그라운드 동작 검증은 아직 수행하지 않았습니다. 광고 14일/기타 알림 30일의 원본 포함 자동 삭제 정책은 기존과 같습니다.
