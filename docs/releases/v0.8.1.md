# Life Dashboard v0.8.1

- 설정 → 데이터 수집 및 권한에 **건강 연결 진단**을 추가했습니다.
- **진단 실행**으로 건강 수집을 다시 시도하고, 실패한 자료형과 단계(권한, 원본 조회·변환, 저장, 변경 이력, 걸음 합계 등)를 기록합니다.
- **진단 결과 보기 · 복사**에서 보고서를 확인하고 복사할 수 있습니다. 건강 수치·기록 내용·레코드 ID·토큰 원문·예외 메시지는 포함하지 않으며 자동 전송하지 않습니다.
- 자동 수집에서도 진단을 기록하며, 재시도가 성공해도 마지막 실패 기록은 유지합니다. 전체 생활 데이터 삭제 시 진단 기록도 지웁니다.
- 수집 상태에 실패 단계와 진단 화면 안내를 표시합니다.

업데이트 후 **설정 → 데이터 수집 및 권한 → 건강 연결 진단 → 진단 실행 → 진단 정보 복사** 순서로 확인할 수 있습니다. 생활 데이터 수집이 켜져 있어야 실행할 수 있습니다.

Android 15 이상 지원. 기존 서명과 DB 구조, SpotTrace 연동·커스텀 카드·테마 기능을 유지합니다.

이번 버전은 Health Connect 수집 오류의 원인을 확인하는 진단 기능을 추가합니다. 보고된 IllegalArgumentException이나 알림 Parcelable 오류 자체가 해결된 버전은 아닙니다. 실제 단말의 새 진단 화면·복사 및 오류 재현은 아직 검증하지 않았습니다.
