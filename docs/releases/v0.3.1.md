# Life Dashboard v0.3.1

지역화폐 결제 인식과 타임라인 상세 표시를 개선했습니다.

- 지역화폐 알림의 원 단위 없는 결제 금액을 인식하고, 인센티브는 별도 정보로 저장합니다. 인센티브는 결제 합계에 더하거나 빼지 않습니다.
- 기존 저장 알림은 새 파서로 재분석하여 결제 분류와 집계를 갱신합니다.
- 타임라인 항목을 누르면 먼저 제목과 내용만 보여줍니다. 아래 상세 보기에서 시간·태그·엔티티·원본 정보를 펼치고 접을 수 있습니다.
- 구조화 데이터와 원본 JSON을 2칸 들여쓰기 및 고정폭 글꼴로 표시하고 텍스트 선택/복사를 지원합니다.

업데이트 후 수집이 활성화되어 있으면 앱 실행 또는 새로고침에서 저장된 이전 알림을 재분석합니다. 수동으로는 설정 → 저장된 원본 다시 분석을 사용할 수 있습니다. 수집되지 않은 과거 알림은 복원할 수 없습니다.

Android 15 이상이 필요합니다. 기존 인증서와 DB 스키마를 유지하며 앱 삭제 없이 업데이트합니다.

검증 범위: 파서·재분석·집계 회귀 테스트와 빌드/lint, 서명·버전 검증. 실제 단말 화면과 업데이트 설치는 미검증입니다. 문제 발생 시 앱 삭제 대신 후속 수정 버전으로 업데이트합니다.
